# Real Estate Market Trends Dashboard

An interactive Power BI dashboard analyzing real estate market 
dynamics built as part of the CodeAlpha Power BI Internship.

## Features
- Property price analysis across different locations
- Rental yield comparisons
- Market demand and supply tracking
- Heat maps showing market hotspots
- Economic indicators visualization

## Tools Used
- Power BI Desktop
- Power Query for data cleaning
- DAX formulas for calculations
- Geographic visualizations

## How to View
1. Download the .pbix file
2. Open it in Power BI Desktop
3. Interact with the dashboard filters and visuals
